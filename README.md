# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built to showcase my education, technical skills, and backend projects. The site features a professional dark-blue theme with minimalist layouts and vibrant accent colors.

## 🔗 Live Demo
View my live portfolio here: https://nagoorbasha6.github.io/Portfolio_project/

---

## 🛠️ Built With

- **HTML5** – Structured semantic elements for clean SEO and readability.
- **CSS3** – Modular layouts utilizing CSS Flexbox, Grid, custom `:root` theme variables, and fluent fluid typography via `clamp()`.
- **GitHub Pages** – Fast and reliable static deployment directly from the repository source.

---

## 🎨 Design & Layout Features

- **Custom Properties Theme:** Built entirely around modular CSS variables (`--navy`, `--cream`, `--lime`, and `--muted`) for quick styling changes.
- **Fluid Typography:** The main headings automatically scale perfectly depending on the viewport size using the dynamic `clamp()` function.
- **Mobile-Responsive Breakpoints:** Fully optimized layout structures that gracefully switch from multi-column rows to stacked vertical panels on mobile devices (< 650px wide).
- **Sticky Top Navigation:** A persistent sticky header layout with integrated smooth scrolling for easy site navigation.

## 💻 How to Run This Project Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd your-repo-name
   ```

3. **Open the project:**
   - Double-click the `index.html` file to open it directly in any modern web browser.
   - Alternatively, if you use VS Code, right-click and select **"Open with Live Server"** to view changes in real-time.

---

## 🚀 How I Deployed This on GitHub Pages

1. Push your updated code to your public GitHub repository.
2. Go to the repository **Settings** tab on GitHub.
3. Scroll down to the **Pages** menu on the left sidebar.
4. Under **Build and deployment**, set the source branch to `main` (or `master`) and folder to `/ (root)`.
5. Click **Save**. Your portfolio site will be live within a couple of minutes!
