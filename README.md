# Personal Portfolio Website

## About the Project
This is my personal portfolio website built using HTML and CSS. It showcases my skills, education, internship experience, projects, and certifications.

## Features
- About Me section
- Technical and soft skills
- Education details
- Internship experience
- Projects showcase
- Certifications
- Contact information and social profile links
- Responsive design for mobile and desktop

## Technologies Used
- HTML
- CSS
- GitHub Pages

## Projects Included
1. **Personal Portfolio Website** – A website to showcase my profile and skills.
2. **Student Management System** – A Python application that manages student information using MySQL.
3. **Student Expense Tracker** – A backend project built using Python, FastAPI, and MySQL.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
